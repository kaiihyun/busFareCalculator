
# Bus Fare Calculator

A web-based bus fare calculator built with HTML, CSS, and JavaScript.

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/kaiihyun/busFareCalculator.git
```

### 2. Open the project

```bash
cd busFareCalculator
```

### 3. Run the project

No additional dependencies or installation are required.

Simply open `index.html` in a web browser.

For the best experience, you can also run it using a local development server such as **VS Code Live Server**.

### Using VS Code Live Server

1. Open the project folder in VS Code.
2. Install the **Live Server** extension if you don't already have it.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The Bus Fare Calculator will open in your browser.

## Requirements

- A modern web browser
- No additional packages or dependencies required
